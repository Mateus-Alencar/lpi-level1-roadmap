#### Ex.2

A) yum install --downloadonly nome_pacote  
B) yum fetch nome_pacote

D) yum list nome_pacote  

Resposta: A  

#### Ex.3
No openSUSE, qual comando do zypper é usado para atualizar todos os pacotes instalados para as versões mais recentes disponíveis nos repositórios configurados?  

A) zypper update  
B) zypper refresh  
C) zypper install --all  
D) zypper patch  

Resposta: A  
> zypper update (ou zypper up) é o comando que efetivamente atualiza os pacotes instalados para as versões mais novas disponíveis nos repositórios.  
> zypper refresh não atualiza pacotes — ele apenas atualiza os metadados dos repositórios (equivalente ao apt-get update ou yum makecache)

A) dnf repoquery  
B) dnf whatprovides  
C) dnf list available  
D) dnf search  

Resposta: B   

#### Ex.5 
Qual das alternativas descreve corretamente a diferença entre yum e dnf?  

A) dnf é usado apenas em sistemas Debian, enquanto yum é exclusivo do RHEL  
B) dnf é o sucessor do yum, mantendo comandos muito semelhantes, com melhorias em desempenho e resolução de dependências  
C) yum é usado apenas para pacotes RPM de código fechado, enquanto dnf gerencia pacotes .deb  
D) Não existe diferença prática entre os dois; são apenas nomes distintos do mesmo binário  

Resposta: B   
#### Ex.6  
Qual comando do rpm você usaria para instalar um pacote .rpm já baixado, forçando a instalação mesmo que existam avisos de dependências não críticas, mas sem ignorar completamente as dependências?  

A) rpm -ivh --nodeps pacote.rpm  
B) rpm -Uvh pacote.rpm  
C) rpm -e pacote.rpm  
D) rpm -qip pacote.rpm  

Resposta: A
> --nodeps faz o RPM pular a verificação de dependências durante a instalação.
