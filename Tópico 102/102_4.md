## Tópico 102.4: Utilização do Sistema de Pacotes Debian  

## 1. Visão Geral

O ecossistema Debian usa arquivos `.deb` como formato de pacote binário. Existem duas camadas principais de ferramentas:

| Camada | Ferramentas | Função |
|---|---|---|
| Baixo nível | `dpkg`, `dpkg-deb`, `dpkg-query` | Instala, remove e consulta pacotes `.deb` individuais, **sem resolver dependências** |
| Alto nível | `apt`, `apt-get`, `apt-cache`, `apt-cdrom`, `aptitude` | Gerencia repositórios, resolve dependências, baixa pacotes da internet |

Distribuições baseadas em Debian: Debian, Ubuntu, Linux Mint, Raspbian/Raspberry Pi OS, Kali Linux, etc.

---

## 2. Arquivo de Configuração de Repositórios

### `/etc/apt/sources.list`

Define de onde os pacotes são obtidos. Formato de cada linha:

```
deb http://deb.debian.org/debian bookworm main contrib non-free
deb-src http://deb.debian.org/debian bookworm main contrib non-free
```

- `deb` → pacotes binários
- `deb-src` → código-fonte
- URL do repositório (mirror)
- Nome da distribuição/release (ex: `bookworm`, `bullseye`, `stable`, `testing`)
- Componentes: `main` (livre), `contrib` (livre mas depende de não-livre), `non-free` (proprietário)

Também é possível haver arquivos adicionais em `/etc/apt/sources.list.d/*.list`.

Chaves de repositórios (GPG) ficam em `/etc/apt/trusted.gpg` ou `/etc/apt/trusted.gpg.d/`.

---

## 3. Ferramenta `apt` / `apt-get` (alto nível)

### 3.1 Atualização de índices

```bash
apt update
```
Baixa e atualiza a lista de pacotes disponíveis nos repositórios configurados (não instala nada).

### 3.2 Atualização de pacotes instalados

```bash
apt upgrade          # atualiza pacotes sem remover nenhum instalado
apt full-upgrade     # (ou apt-get dist-upgrade) atualiza podendo instalar/remover pacotes para resolver dependências
```

### 3.3 Instalação e remoção

```bash
apt install pacote            # instala um pacote e suas dependências
apt install pacote=1.2.3-1    # instala versão específica
apt remove pacote             # remove o pacote, mantém arquivos de configuração
apt purge pacote               # remove o pacote E seus arquivos de configuração
apt autoremove                 # remove dependências órfãs que não são mais necessárias
```

### 3.4 Busca e informações

```bash
apt search termo        # busca pacotes pelo nome/descrição
apt show pacote          # exibe detalhes (versão, dependências, tamanho, descrição)
apt list --installed     # lista pacotes instalados
apt list --upgradable    # lista pacotes com atualização disponível
```

### 3.5 Limpeza de cache

```bash
apt clean       # remove todos os .deb baixados de /var/cache/apt/archives
apt autoclean   # remove apenas os .deb obsoletos (versões antigas)
```

### 3.6 `apt-cache` (consulta ao cache local, sem tocar no sistema)

```bash
apt-cache search termo        # busca pacotes
apt-cache show pacote          # mostra metadados do pacote
apt-cache depends pacote       # lista dependências
apt-cache rdepends pacote      # lista pacotes que dependem dele (dependências reversas)
apt-cache policy pacote        # mostra versão instalada x versões disponíveis e prioridades
```

> **Nota para a prova:** `apt` é a ferramenta moderna, unificada (combina funções de `apt-get` e `apt-cache`) e pensada para uso interativo. `apt-get`/`apt-cache` são as ferramentas clássicas, mais estáveis para uso em scripts.

> [!NOTE]  
> **Metadados**: São informações estruturadas que descrevem o conteúdo, a origem, a versão e as regras de funcionamento de um pacote

## 4. Ferramenta `dpkg` (baixo nível)

`dpkg` trabalha diretamente com arquivos `.deb` locais e com o banco de dados de pacotes instalados. **Não resolve dependências pela rede.**

### 4.1 Instalação e remoção

```bash
dpkg -i pacote.deb         # (--install) instala um arquivo .deb local
dpkg -r pacote              # (--remove) remove o pacote, mantém configs
dpkg -P pacote              # (--purge) remove pacote e configs
```

Se `dpkg -i` falhar por dependência faltando, o erro comum é resolvido com:

```bash
apt-get install -f          # (--fix-broken) corrige/instala dependências pendentes
```

### 4.2 Consulta (query)

```bash
dpkg -l                     # (--list) lista todos os pacotes instalados
dpkg -l 'apache*'           # lista pacotes cujo nome casa com o padrão
dpkg -s pacote               # (--status) mostra status/detalhes de um pacote instalado
dpkg -L pacote                # (--listfiles) lista arquivos instalados pelo pacote
dpkg -S /caminho/arquivo      # (--search) descobre a qual pacote um arquivo pertence
```

### 4.3 Trabalhando com arquivos `.deb` (ainda não instalados)

```bash
dpkg-deb -c pacote.deb        # lista conteúdo (arquivos) do .deb
dpkg-deb -I pacote.deb        # mostra informações/metadados do pacote (--info)
dpkg-deb -x pacote.deb dir/   # extrai o conteúdo sem instalar
```

### 4.4 Reconfiguração

```bash
dpkg-reconfigure pacote       # refaz a configuração interativa (debconf) de um pacote já instalado
```

### 4.5 Estados de um pacote (`dpkg -l`)

Coluna de status mostra três letras, ex: `ii`, `rc`, `un`:

| Posição | Significado | Valores comuns |
|---|---|---|
| 1ª (desejado) | `i`=install, `r`=remove, `p`=purge, `h`=hold |
| 2ª (atual) | `i`=installed, `c`=config-files, `n`=not-installed, `U`=unpacked, `H`=half-installed |
| 3ª (erro) | espaço=ok, `R`=reinst-required |

Exemplo: `ii` = instalado corretamente; `rc` = removido mas ainda tem arquivos de configuração.

## 5. Retendo pacotes (hold)

Impede que um pacote seja atualizado automaticamente:

```bash
apt-mark hold pacote      # marca pacote como retido
apt-mark unhold pacote    # remove a retenção
apt-mark showhold         # lista pacotes retidos
```

Equivalente via `dpkg`:
```bash
echo "pacote hold" | dpkg --set-selections
```

---

## 6. Reconstrução/Reconfiguração e Debconf

- `debconf` é o sistema que gerencia perguntas de configuração durante instalação de pacotes.
- `dpkg-reconfigure -plow pacote` permite ver todas as perguntas (baixo nível de prioridade).

---

## 7. `aptitude` (ferramenta alternativa, também cobrada)

Interface em modo texto (ncurses) e linha de comando que também gerencia pacotes e dependências:

```bash
aptitude               # abre interface interativa
aptitude search termo
aptitude install pacote
aptitude remove pacote
aptitude update
aptitude upgrade
```

---

## 8. Quadro-resumo de comandos essenciais

| Tarefa | Comando |
|---|---|
| Atualizar lista de pacotes | `apt update` |
| Atualizar pacotes instalados | `apt upgrade` / `apt full-upgrade` |
| Instalar pacote (repositório) | `apt install pacote` |
| Instalar pacote (.deb local) | `dpkg -i pacote.deb` |
| Remover pacote (mantém config) | `apt remove pacote` / `dpkg -r pacote` |
| Remover pacote + config | `apt purge pacote` / `dpkg -P pacote` |
| Corrigir dependências quebradas | `apt-get install -f` |
| Buscar pacote | `apt search` / `apt-cache search` |
| Ver info de pacote | `apt show` / `dpkg -s` |
| Listar arquivos de um pacote | `dpkg -L pacote` |
| Descobrir dono de um arquivo | `dpkg -S /caminho` |
| Listar pacotes instalados | `dpkg -l` / `apt list --installed` |
| Remover órfãos | `apt autoremove` |
| Limpar cache de .deb | `apt clean` / `apt autoclean` |
| Reter/liberar pacote | `apt-mark hold/unhold` |

## 9. Pontos de atenção  

1. **`dpkg` NÃO resolve dependências** — só `apt`/`apt-get`/`aptitude` fazem isso automaticamente.
2. Diferença entre `remove` (mantém `/etc/pacote/*`) e `purge` (apaga tudo, inclusive configs).
3. `apt-get update` **não atualiza pacotes**, apenas os índices/listas de repositórios.
4. Arquivo principal de repositórios: `/etc/apt/sources.list` (mais `sources.list.d/`).
5. Cache local de `.deb` baixados: `/var/cache/apt/archives/`.
6. `apt-cache policy` é útil para entender por que uma versão específica está sendo escolhida (prioridades/pinning).
7. Saber interpretar a saída de `dpkg -l` (códigos de estado de 2-3 letras).
8. `apt` (comando moderno) x `apt-get`/`apt-cache` (comandos clássicos, mesma finalidade dividida em dois binários).
