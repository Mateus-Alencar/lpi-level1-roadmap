# /g

## 1. Visão geral e objetivos do exame

O **vi** é o editor de texto em modo terminal presente em praticamente todo sistema Unix/Linux. Mesmo quando não há interface gráfica, nano ou outro editor instalado, o `vi` (ou um `vim` compatível) quase sempre está lá. Por isso a LPI cobra seu uso básico: um administrador precisa conseguir editar arquivos de configuração em qualquer situação, inclusive em modo de recuperação.

**Áreas de conhecimento cobertas pelo exame:**

- Navegar em um documento usando o vi.
- Usar os modos básicos do vi.
- Inserir, editar, excluir, copiar e localizar texto.

**Termos, arquivos e utilitários que aparecem na ementa:**

`vi`, `/`, `?`, `h`, `j`, `k`, `l`, `i`, `o`, `a`, `c`, `d`, `p`, `y`, `dd`, `yy`, `ZZ`, `:w!`, `:q!`, além do conhecimento de existência do **Emacs**, **nano** e **vim**.

> **Dica de prova:** a prova adora perguntar *qual tecla/comando faz X* e *em qual modo você está*. Memorize os comandos, mas principalmente entenda a lógica por trás deles.

## 2. Editores de texto em Linux: panorama

| Editor | Características |
|---|---|
| **vi** | Editor original, modal, leve, padrão POSIX. Presente em quase todo sistema. |
| **vim** (*Vi IMproved*) | Versão estendida do vi: realce de sintaxe, desfazer múltiplo, modo visual, plugins. Em muitas distribuições, `vi` é um link ou alias para `vim`. |
| **nano** | Simples, não modal, mostra atalhos na parte inferior da tela. Ótimo para iniciantes. |
| **emacs** | Editor extenso e extensível, não modal, baseado em atalhos com `Ctrl` e `Alt`. |
| **ed / ex** | Editores de linha; o `ex` é o "modo de comando" do vi. |

Para o exame basta saber que **nano** e **Emacs** existem e que o **vim** é uma evolução do vi. O foco real é o vi.

### 2.1 Qual editor o sistema usa por padrão?

Várias ferramentas (`crontab -e`, `visudo`, `git commit`, `sudoedit`) abrem um editor definido por variáveis de ambiente:

```bash
export EDITOR=vi      # editor padrão para edição simples
export VISUAL=vi      # editor de tela cheia (tem prioridade sobre EDITOR em vários programas)
```

Em sistemas Debian/Ubuntu, o editor padrão do sistema pode ser alterado com:

```bash
sudo update-alternatives --config editor
```

### 2.2 Ferramentas que abrem o vi/editor

- `visudo` – edita `/etc/sudoers` com verificação de sintaxe.
- `vipw` / `vigr` – editam `/etc/passwd` e `/etc/group` com travamento de arquivo.
- `crontab -e` – edita a crontab do usuário.
- `sudoedit` / `sudo -e` – edita arquivos com segurança como outro usuário.

## 3. A ideia central: o vi é um editor *modal*

A maior barreira para iniciantes é entender que, no vi, **a mesma tecla faz coisas diferentes dependendo do modo**. Em um editor comum, digitar `d` insere a letra "d". No vi, dependendo do modo, `d` pode ser o início de um comando de exclusão.

### 3.1 Os três modos principais

| Modo | Para que serve | Como entrar | Como sair |
|---|---|---|---|
| **Modo normal** (ou de comando) | Navegar, apagar, copiar, colar, desfazer. É o modo **padrão** ao abrir o vi. | `Esc` (a partir de qualquer outro modo) | Digitar um comando de inserção ou `:` |
| **Modo de inserção** | Digitar texto de verdade. | `i`, `a`, `o`, `I`, `A`, `O`, `c...`, `s`, etc. | `Esc` |
| **Modo de última linha** (*ex mode* / linha de comando) | Salvar, sair, buscar, substituir, comandos do `ex`. | `:` (ou `/` e `?` para busca) | `Enter` (executa) ou `Esc` (cancela) |

No **vim** existe ainda o **modo visual** (`v`, `V`, `Ctrl+v`) e o **modo de substituição** (`R`), mas o essencial para o exame são os três acima.

### 3.2 Regra de ouro

> **Na dúvida sobre em que modo está, aperte `Esc` duas vezes.** Você sempre voltará ao modo normal.

No vim, o rodapé mostra `-- INSERT --` quando você está em modo de inserção. No vi clássico, nem sempre há indicador, o que torna o hábito do `Esc` ainda mais importante.

## 4. Abrindo e fechando o vi

### 4.1 Abrir arquivos

```bash
vi arquivo.txt            # abre (ou cria, ao salvar) arquivo.txt
vi +10 arquivo.txt        # abre já na linha 10
vi + arquivo.txt          # abre no final do arquivo
vi +/palavra arquivo.txt  # abre na primeira ocorrência de "palavra"
vi -R arquivo.txt         # abre somente leitura (também: view arquivo.txt)
vi arq1 arq2              # abre vários arquivos (use :n para o próximo)
```

Se o arquivo não existir, o vi abre um buffer vazio e o arquivo só será criado quando você salvar.

### 4.2 Salvar e sair (modo de última linha)

| Comando | Ação |
|---|---|
| `:w` | Grava (salva) o arquivo e continua no vi. |
| `:w nome` | Grava com outro nome ("salvar como"). |
| `:q` | Sai. Só funciona se **não houver alterações** não salvas. |
| `:wq` | Grava e sai. |
| `:x` | Grava **somente se houve alteração** e sai. |
| `ZZ` | (modo normal) Equivale a `:x`: grava e sai. |
| `:q!` | Sai **descartando** as alterações. |
| `:w!` | Força a gravação (útil quando o arquivo é somente leitura, desde que você tenha permissão para forçar). |
| `:wq!` | Força gravar e sair. |
| `ZQ` | (modo normal, vim) Sai sem gravar, equivale a `:q!`. |
| `:e!` | Recarrega o arquivo do disco, descartando alterações. |

**Cuidado com o `!`:** ele significa "force" / "não pergunte". `:q!` descarta tudo sem confirmação.

## 5. Navegação (modo normal)

### 5.1 Movimento básico

No vi, as setas do teclado podem não funcionar em todos os terminais. Os comandos clássicos usam a linha central do teclado:

| Tecla | Movimento |
|---|---|
| `h` | Um caractere para a **esquerda** |
| `j` | Uma linha para **baixo** |
| `k` | Uma linha para **cima** |
| `l` | Um caractere para a **direita** |

**Macete para memorizar:** o `j` parece uma seta para baixo (tem o "gancho" descendo), e o `h` está mais à esquerda, o `l` mais à direita.

É possível usar **prefixo numérico**: `5j` desce 5 linhas, `10l` anda 10 caracteres à direita, `3k` sobe 3 linhas.

### 5.2 Movimento por palavras

| Tecla | Movimento |
|---|---|
| `w` | Início da **próxima palavra** |
| `b` | Início da palavra **anterior** (*back*) |
| `e` | **Final** da palavra atual/próxima (*end*) |
| `W`, `B`, `E` | Mesmo que acima, mas considerando "palavra" como tudo separado por espaço (ignora pontuação) |

Exemplo: `3w` avança três palavras.

### 5.3 Movimento dentro da linha

| Tecla | Movimento |
|---|---|
| `0` (zero) | **Início** da linha (coluna 1) |
| `^` | Primeiro caractere **não branco** da linha |
| `$` | **Final** da linha |

Note que `0`, `^` e `$` lembram as âncoras de **expressões regulares** (`^` início, `$` fim). Essa lógica se repete no `grep`, `sed` e no próprio vi.

### 5.4 Movimento por linhas e blocos

| Tecla | Movimento |
|---|---|
| `G` | Vai para a **última linha** do arquivo |
| `1G` ou `gg` | Vai para a **primeira linha** (`gg` é do vim) |
| `nG` | Vai para a linha **n** (ex.: `25G`) |
| `:n` | Vai para a linha n (ex.: `:25`) |
| `H` | Topo da tela (*High*) |
| `M` | Meio da tela (*Middle*) |
| `L` | Fim da tela (*Low*) |
| `(` e `)` | Início da frase anterior / próxima |
| `{` e `}` | Início do parágrafo anterior / próximo |
| `%` | Pula para o par do parêntese, colchete ou chave sob o cursor |

### 5.5 Rolagem de tela

| Tecla | Ação |
|---|---|
| `Ctrl+f` | Avança uma tela inteira (*forward*) |
| `Ctrl+b` | Volta uma tela inteira (*backward*) |
| `Ctrl+d` | Desce meia tela (*down*) |
| `Ctrl+u` | Sobe meia tela (*up*) |
| `Ctrl+g` | Mostra nome do arquivo, linha atual e total de linhas |

## 6. Entrando no modo de inserção

Existem várias formas de começar a digitar, e a diferença está **onde** o texto será inserido:

| Tecla | Onde começa a inserção |
|---|---|
| `i` | **Antes** do cursor (*insert*) |
| `a` | **Depois** do cursor (*append*) |
| `I` | No **início da linha** (primeiro caractere não branco) |
| `A` | No **final da linha** |
| `o` | Abre uma **nova linha abaixo** da atual (*open*) |
| `O` | Abre uma **nova linha acima** da atual |
| `s` | Apaga o caractere sob o cursor e entra em inserção (*substitute*) |
| `S` | Apaga a linha inteira e entra em inserção |
| `cc` | Mesmo efeito de `S` |

**Padrão fácil:** a letra **minúscula** age em relação ao cursor; a **MAIÚSCULA** age em relação à **linha inteira**. Esse padrão aparece em vários pares (`i/I`, `a/A`, `o/O`, `p/P`, `x/X`, `d/D`, `c/C`, `r/R`).

Para voltar ao modo normal, pressione **`Esc`**.

## 7. Editando, apagando e alterando texto

### 7.1 Apagar (excluir)

| Comando | Ação |
|---|---|
| `x` | Apaga o caractere **sob** o cursor |
| `X` | Apaga o caractere **antes** do cursor (como Backspace) |
| `dd` | Apaga a **linha inteira** |
| `D` (ou `d$`) | Apaga do cursor até o **final da linha** |
| `d0` | Apaga do cursor até o **início da linha** |
| `dw` | Apaga do cursor até o início da próxima palavra |
| `db` | Apaga a palavra anterior |
| `5dd` | Apaga **5 linhas** a partir da atual |
| `d5w` ou `5dw` | Apaga 5 palavras |
| `dG` | Apaga da linha atual até o **fim do arquivo** |
| `dgg` | Apaga da linha atual até o **início do arquivo** (vim) |

**Importante:** o que é apagado com `d` vai para um **registrador** (área de transferência interna do vi). Ou seja, `dd` funciona como **recortar**, e `p` pode colar o que foi apagado.

### 7.2 A gramática dos comandos do vi

A grande sacada do vi é que os comandos formam uma "linguagem":

```
[quantidade] + operador + [quantidade] + movimento
```

- **Operadores:** `d` (delete), `y` (yank/copiar), `c` (change/alterar).
- **Movimentos:** `w`, `b`, `e`, `$`, `0`, `G`, `}`, etc.

Combinando-os, você cria dezenas de comandos sem decorar cada um:

| Combinação | Resultado |
|---|---|
| `dw` | apaga uma palavra |
| `d$` | apaga até o fim da linha |
| `yw` | copia uma palavra |
| `y$` | copia até o fim da linha |
| `cw` | altera (apaga e entra em inserção) uma palavra |
| `c$` ou `C` | altera até o fim da linha |
| `d3w` | apaga 3 palavras |
| `y}` | copia até o fim do parágrafo |

Quando o operador é **dobrado** (`dd`, `yy`, `cc`), ele age sobre a **linha inteira**.

### 7.3 Alterar (substituir) texto

| Comando | Ação |
|---|---|
| `r` + caractere | Substitui **um** caractere e **permanece** em modo normal (ex.: `rx` troca o caractere por x) |
| `R` | Entra em modo de **sobrescrita**: cada letra digitada substitui a existente, até `Esc` |
| `cw` | Altera a palavra: apaga até o fim dela e entra em inserção |
| `cc` / `S` | Altera a linha inteira |
| `C` | Altera do cursor até o fim da linha |
| `~` | Inverte maiúscula/minúscula do caractere sob o cursor |
| `J` | **Junta** a linha atual com a seguinte (*Join*) |

### 7.4 Desfazer e refazer

| Comando | Ação |
|---|---|
| `u` | **Desfaz** a última alteração (*undo*) |
| `U` | Desfaz todas as alterações feitas na **linha atual** (vi clássico) |
| `Ctrl+r` | **Refaz** (*redo*) – disponível no vim |
| `.` | **Repete** o último comando de alteração |

> No vi clássico, `u` desfaz apenas **um** nível, e apertar `u` de novo desfaz o próprio desfazer. No **vim**, `u` pode ser repetido várias vezes e `Ctrl+r` refaz.

## 8. Copiar, recortar e colar

No vi, "copiar" se chama **yank**. Tudo que é apagado (`d`) ou copiado (`y`) vai para um registrador, e `p` cola.

### 8.1 Copiar (yank)

| Comando | Ação |
|---|---|
| `yy` ou `Y` | Copia a **linha inteira** |
| `3yy` | Copia **3 linhas** |
| `yw` | Copia uma palavra |
| `y$` | Copia até o fim da linha |
| `y0` | Copia até o início da linha |
| `yG` | Copia até o fim do arquivo |

### 8.2 Colar (put)

| Comando | Ação |
|---|---|
| `p` | Cola **depois** do cursor (ou **abaixo** da linha, se foi copiada uma linha inteira) |
| `P` | Cola **antes** do cursor (ou **acima** da linha) |

### 8.3 Receitas práticas

- **Copiar e colar uma linha:** `yy` → mover para o destino → `p`.
- **Mover (recortar e colar) uma linha:** `dd` → mover → `p`.
- **Duplicar a linha atual:** `yyp`.
- **Trocar duas linhas de lugar:** `ddp`.
- **Trocar dois caracteres:** `xp`.

### 8.4 Registradores nomeados (extra)

É possível usar mais de uma área de transferência: `"ayy` copia a linha para o registrador **a**; `"ap` cola o conteúdo do registrador **a**. É um recurso além do mínimo cobrado, mas ajuda a entender que `d`, `y` e `p` trabalham com registradores.

## 9. Busca e substituição

### 9.1 Buscar texto

| Comando | Ação |
|---|---|
| `/padrão` | Busca **para frente** (para baixo no arquivo) |
| `?padrão` | Busca **para trás** (para cima no arquivo) |
| `n` | Próxima ocorrência, **na mesma direção** da busca |
| `N` | Ocorrência anterior, **na direção oposta** |
| `*` | Busca pela palavra sob o cursor, para frente (vim) |
| `#` | Busca pela palavra sob o cursor, para trás (vim) |

A busca aceita **expressões regulares**. Exemplo: `/^root` encontra "root" no **início** de linha; `/bash$` encontra "bash" no **fim** de linha.

Por padrão a busca diferencia maiúsculas de minúsculas. Para ignorar: `:set ignorecase` (ou `:set ic`).

**Detalhe de prova:** depois de `?padrão`, a tecla `n` continua buscando **para trás**, e `N` busca para frente.

### 9.2 Buscar caractere dentro da linha

| Comando | Ação |
|---|---|
| `fx` | Vai até a próxima ocorrência do caractere **x** na linha |
| `Fx` | Mesmo, mas para trás |
| `;` | Repete a última busca `f`/`F` |

### 9.3 Substituir (comando `:s`)

A substituição vem do editor `ex` e tem a sintaxe:

```
:[intervalo]s/padrão/substituição/[flags]
```

| Comando | Efeito |
|---|---|
| `:s/velho/novo/` | Troca a **primeira** ocorrência **na linha atual** |
| `:s/velho/novo/g` | Troca **todas** as ocorrências na linha atual (`g` = global na linha) |
| `:%s/velho/novo/g` | Troca todas as ocorrências no **arquivo inteiro** (`%` = todas as linhas) |
| `:%s/velho/novo/gc` | Igual, mas **pede confirmação** a cada troca (`c` = confirm) |
| `:5,12s/velho/novo/g` | Aplica apenas nas linhas 5 a 12 |
| `:.,$s/velho/novo/g` | Da linha atual (`.`) até a última (`$`) |

O delimitador `/` pode ser trocado por outro caractere quando o texto contém barras, por exemplo `:%s#/usr/bin#/opt/bin#g`.

### 9.4 Outros comandos de última linha úteis

| Comando | Ação |
|---|---|
| `:set number` (`:set nu`) | Mostra números de linha |
| `:set nonumber` (`:set nonu`) | Oculta números de linha |
| `:set ignorecase` | Busca sem diferenciar maiúsculas/minúsculas |
| `:set list` | Mostra caracteres invisíveis (tabs, fim de linha) |
| `:syntax on` | Ativa realce de sintaxe (vim) |
| `:!comando` | Executa um comando do shell sem sair do vi (ex.: `:!ls`) |
| `:r arquivo` | **Insere** o conteúdo de outro arquivo abaixo do cursor |
| `:r !comando` | Insere a **saída** de um comando (ex.: `:r !date`) |
| `:5,10d` | Apaga as linhas 5 a 10 |
| `:5,10y` | Copia as linhas 5 a 10 |
| `:n` / `:N` | Próximo / anterior arquivo (quando abriu vários) |

## 10. Configuração do vi/vim

As opções definidas com `:set` valem apenas para a sessão atual. Para torná-las permanentes:

- **vi / ex clássico:** arquivo `~/.exrc`
- **vim:** arquivo `~/.vimrc` (global: `/etc/vimrc` ou `/etc/vim/vimrc`)

Exemplo de `~/.vimrc`:

```vim
set number
set ignorecase
set tabstop=4
set shiftwidth=4
syntax on
```

Linhas de comentário no `.vimrc` começam com aspas duplas (`"`).

## 11. Tutorial interativo: `vimtutor`

O comando `vimtutor` abre um tutorial de cerca de 30 minutos, dentro do próprio vim. É a melhor forma prática de fixar os comandos. Se o pacote `vim` estiver instalado, o `vimtutor` geralmente vem junto.

## 12. Arquivos temporários: swap e recuperação

Quando você abre `arquivo.txt`, o vim cria um arquivo de **swap** (`.arquivo.txt.swp`) no mesmo diretório. Ele guarda as alterações em andamento. Se o editor ou a sessão cair, ao reabrir o arquivo o vim avisa que existe um swap e oferece recuperação:

```bash
vi -r arquivo.txt     # recupera o arquivo a partir do swap
```

Se você tem certeza de que nenhum outro vi está usando o arquivo, pode apagar o `.swp` residual. O swap é removido automaticamente quando você sai normalmente.

## 13. Roteiro prático passo a passo

Simulação de uma edição real: alterar a porta do SSH em um arquivo de configuração de teste.

1. `vi sshd_teste.conf` – abre o arquivo (modo normal).
2. `/Port` + `Enter` – busca a linha com "Port".
3. `A` – vai para o fim da linha e entra em inserção.
4. `Backspace` apaga o valor antigo; digite `2222`.
5. `Esc` – volta ao modo normal.
6. `:wq` + `Enter` – grava e sai.

Outro cenário: **apagar todas as linhas de comentário** de um arquivo:

```
:g/^#/d
```

(`:g` aplica um comando a todas as linhas que casam com o padrão; aqui, `d` apaga as que começam com `#`.)

## 15. Pegadinhas e pontos de atenção para a prova

1. **O vi abre em modo normal**, não em modo de inserção. Digitar texto direto causa comandos inesperados.
2. **`:q` falha** se houver alterações não salvas; use `:q!` para descartar ou `:wq` para gravar.
3. **`ZZ` não usa `:`** e não precisa de `Enter`. É um comando do modo normal.
4. **`x` apaga o caractere sob o cursor; `X`, o anterior.** `dd` apaga a linha; `D` apaga até o fim da linha.
5. **`p` cola depois; `P` cola antes.**
6. **`n` segue a direção da busca**: após `?`, `n` volta no arquivo. `N` inverte.
7. **`r` substitui um caractere** e fica em modo normal; **`R` entra em sobrescrita**.
8. **`o` abre linha abaixo; `O`, acima.**
9. **`yy` copia, `dd` recorta, `p`/`P` cola**: o `dd` também alimenta o registrador.
10. **`:w!` e `:q!` usam `!` para forçar**; `:w!` não contorna falta de permissão do sistema de arquivos para quem não tem direito algum.
11. **`:x` só grava se houve alteração**, ao contrário de `:wq`, que sempre grava (atualiza a data de modificação).
12. **`vi` e `vim` não são sempre a mesma coisa**: algumas funções (`Ctrl+r`, `gg`, múltiplos desfazer, modo visual, realce de sintaxe) são do **vim**.
13. **`~/.vimrc`** configura o vim; **`~/.exrc`** configura o vi clássico.
14. Os editores **nano** e **Emacs** são **não modais**; o vi/vim é **modal**.

## 16. Exemplos de questões no estilo LPI

**1.** Qual sequência grava as alterações e sai do vi?

- a) `:q!`
- b) `:wq`
- c) `:w!`
- d) `ZQ`

*Resposta: **b**. (`ZZ` e `:x` também fariam isso.)*

**2.** Em modo normal, qual comando duplica a linha atual logo abaixo dela?

*Resposta: **`yyp`**.*

**3.** Após pesquisar com `/erro`, qual tecla busca a ocorrência **anterior**?

*Resposta: **`N`**.*

**4.** Qual comando troca todas as ocorrências de "foo" por "bar" em todo o arquivo?

*Resposta: **`:%s/foo/bar/g`**.*

**5.** Qual tecla abre uma linha em branco acima da atual e entra em modo de inserção?

*Resposta: **`O`** (maiúsculo).*
