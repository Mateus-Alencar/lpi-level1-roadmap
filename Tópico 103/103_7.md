## 1. Objetivos oficiais

- Criar expressões regulares simples contendo vários elementos de notação.
- Entender as **diferenças entre expressões regulares básicas (BRE) e estendidas (ERE)**.
- Entender os conceitos de **caracteres especiais, classes de caracteres, quantificadores e âncoras**.
- Usar ferramentas de regex para **procurar** em sistemas de arquivos ou no conteúdo de arquivos.
- Usar regex para **excluir, alterar e substituir** texto.

Utilitários e documentação da lista oficial:

| Item | Função |
|------|--------|
| `grep` | Filtra **linhas** que casam com um padrão |
| `egrep` | Equivale a `grep -E` (regex estendida) |
| `fgrep` | Equivale a `grep -F` (texto literal, sem regex) |
| `sed` | Editor de fluxo: busca **e substitui/apaga/imprime** |
| `regex(7)` | Página de manual que descreve a sintaxe (`man 7 regex`) |

## 2. Regex × globbing do shell

São coisas **diferentes**, e confundi-las é fonte de erro clássico.

| Aspecto | Globbing (shell) | Expressão regular |
|---------|------------------|-------------------|
| Quem interpreta | O **shell**, antes de rodar o comando | O **programa** (`grep`, `sed`...) |
| Serve para | Casar **nomes de arquivos** | Casar **conteúdo de texto** |
| "Qualquer sequência" | `*` | `.*` |
| "Um caractere qualquer" | `?` | `.` |
| `*` significa | Qualquer coisa | **Zero ou mais** do item anterior |

```bash
ls *.txt             # glob: o shell expande para os arquivos .txt
grep 'a.*b' log.txt  # regex: o grep interpreta 'a.*b'
```

### 2.1 Sempre use aspas simples no padrão

Sem aspas, o **shell** pode interpretar `*`, `?`, `$`, `\` e `[ ]` antes do `grep`:

```bash
grep ^root /etc/passwd      # funciona, mas é frágil
grep '^root' /etc/passwd    # recomendado
grep "$HOME" arquivo        # aspas duplas: $HOME é EXPANDIDO pelo shell
grep '$HOME' arquivo        # aspas simples: procura o texto literal $HOME
```

> Regra prática: **aspas simples** protegem o padrão da interpretação do shell.

## 3. BRE × ERE: o ponto central do tópico

Existem dois "dialetos" de regex nas ferramentas do exame:

- **BRE** (*Basic Regular Expressions*): padrão do `grep` e do `sed`.
- **ERE** (*Extended Regular Expressions*): `grep -E`, `egrep`, `sed -E` (ou `sed -r`).

### 3.1 A diferença essencial

Em **BRE**, os caracteres `+ ? | { } ( )` são **literais**. Para dar a eles sentido especial é preciso **escapar com barra invertida**.

Em **ERE**, é o **contrário**: eles já são especiais, e a barra invertida os torna literais.

| Função | BRE (`grep`, `sed`) | ERE (`grep -E`, `sed -E`) |
|--------|---------------------|---------------------------|
| Um ou mais | `\+` | `+` |
| Zero ou um | `\?` | `?` |
| Repetição `n` vezes | `\{n\}` | `{n}` |
| Repetição `n` a `m` | `\{n,m\}` | `{n,m}` |
| Agrupamento | `\( \)` | `( )` |
| Retrovisor (backreference) | `\1` | `\1` |

Alternância ("OU"):

```bash
grep 'gato\|cachorro' animais.txt       # BRE (extensão GNU): \|
grep -E 'gato|cachorro' animais.txt     # ERE: |
```

### 3.2 O mesmo padrão, dois dialetos

```bash
# "um ou mais dígitos"
grep '[0-9]\+' arquivo        # BRE
grep -E '[0-9]+' arquivo      # ERE

# "exatamente 3 letras a"
grep 'a\{3\}' arquivo         # BRE
grep -E 'a{3}' arquivo        # ERE

# "ab repetido uma ou mais vezes"
grep '\(ab\)\+' arquivo       # BRE
grep -E '(ab)+' arquivo       # ERE
```

### 3.3 Atenção: o POSIX puro e o GNU

No **POSIX estrito**, a BRE **não** tem `\+`, `\?` nem `\|`. O **GNU grep/sed** (o que a prova considera no Linux) **aceita** essas formas como extensão. Por isso, nas questões do LPIC:

- `\+`, `\?`, `\|` em `grep` comum funcionam no Linux.
- `+`, `?`, `|`, `(`, `)`, `{`, `}` **sem** barra e **sem** `-E` são tratados como **caracteres literais**.

```bash
echo "a+b" | grep 'a+b'      # casa: o + é literal na BRE
echo "aab" | grep 'a+b'      # NÃO casa: procura "a+b" literal
echo "aab" | grep -E 'a+b'   # casa: + é quantificador na ERE
```

## 4. Metacaracteres e âncoras

### 4.1 Tabela de metacaracteres (comuns a BRE e ERE)

| Símbolo | Significado |
|---------|-------------|
| `.` | **Qualquer um** caractere (exceto quebra de linha) |
| `*` | **Zero ou mais** ocorrências do item anterior |
| `[ ]` | Um caractere **dentre** os listados |
| `[^ ]` | Um caractere **que não esteja** entre os listados |
| `^` | **Início** da linha (fora de colchetes) |
| `$` | **Fim** da linha |
| `\` | **Escapa** o caractere seguinte (o torna literal) ou introduz uma sequência |

### 4.2 Âncoras

| Âncora | Onde casa |
|--------|-----------|
| `^` | Início da linha |
| `$` | Fim da linha |
| `\<` | Início de **palavra** |
| `\>` | Fim de **palavra** |
| `\b` | **Limite** de palavra (início ou fim) |
| `\B` | Onde **não** há limite de palavra |

```bash
grep '^root' /etc/passwd        # linhas que COMEÇAM com root
grep 'bash$' /etc/passwd        # linhas que TERMINAM com bash
grep '^$' arquivo               # linhas VAZIAS
grep -v '^$' arquivo            # tudo, exceto linhas vazias
grep '^#' /etc/fstab            # linhas que começam com # (comentários)
grep -v '^#' /etc/fstab         # sem comentários
grep -v '^\s*#\|^$' arquivo     # sem comentários e sem linhas vazias
```

### 4.3 Casos especiais de `^`, `$` e `*` na BRE

- `^` só é âncora **no início** do padrão (ou após `\(` / `\|`). Em outras posições é literal na BRE.
- `$` só é âncora **no fim** do padrão. Em outras posições é literal na BRE.
- `*` **no início** do padrão (ou logo após `\(` ou `^`) é um asterisco **literal**.

```bash
echo 'a^b' | grep 'a^b'      # casa (^ no meio é literal na BRE)
echo '*abc' | grep '*abc'    # casa (* inicial é literal)
```

### 4.4 Escapando metacaracteres

Para procurar o caractere literal, escape-o:

```bash
grep '192\.168\.0\.1' arquivo     # pontos literais
grep 'R\$ 10' arquivo             # cifrão literal
grep '\*' arquivo                 # asterisco literal
grep '\[ERRO\]' log               # colchetes literais
grep '\\' arquivo                 # barra invertida literal
```

> Esquecer de escapar o `.` é erro frequente: `192.168.0.1` também casa `192x168y0z1`.

### 4.5 `.*` é "ganancioso" (greedy)

`.*` casa **o máximo possível** na linha:

```bash
echo '<b>negrito</b> e <i>itálico</i>' | sed 's/<.*>//'
# Resultado: (vazio) — .* engoliu desde o primeiro < até o último >

echo '<b>negrito</b> e <i>itálico</i>' | sed 's/<[^>]*>//g'
# Resultado: negrito e itálico
```

A técnica `[^>]*` ("tudo, menos >") é o jeito padrão de contornar a ganância em BRE/ERE.

## 5. Expressões de colchetes e classes POSIX

### 5.1 Listas e intervalos

```bash
[abc]        # a, b ou c
[a-z]        # uma letra minúscula
[A-Z]        # uma letra maiúscula
[0-9]        # um dígito
[a-zA-Z0-9]  # alfanumérico
[^0-9]       # qualquer coisa que NÃO seja dígito
[^aeiou]     # qualquer caractere que não seja vogal minúscula
```

### 5.2 Classes POSIX (use **dentro** de colchetes duplos)

| Classe | Equivale a | Descrição |
|--------|-----------|-----------|
| `[:alpha:]` | `A-Za-z` | Letras |
| `[:digit:]` | `0-9` | Dígitos |
| `[:alnum:]` | letras + dígitos | Alfanuméricos |
| `[:upper:]` | `A-Z` | Maiúsculas |
| `[:lower:]` | `a-z` | Minúsculas |
| `[:space:]` | espaço, `\t`, `\n`, `\r`, `\v`, `\f` | Qualquer espaço em branco |
| `[:blank:]` | espaço e `\t` | Espaço e tabulação |
| `[:punct:]` | `! " # $ % & ' ( ) * + , - . / : ; < = > ? @ [ \ ] ^ _ ` { ... } ~` | Pontuação |
| `[:xdigit:]` | `0-9A-Fa-f` | Dígitos hexadecimais |
| `[:cntrl:]` | caracteres de controle | |
| `[:print:]` | imprimíveis (inclui espaço) | |
| `[:graph:]` | imprimíveis (sem espaço) | |

```bash
grep '[[:digit:]]' arquivo          # contém ao menos um dígito
grep '^[[:upper:]]' arquivo         # começa com maiúscula
grep '[[:space:]]$' arquivo         # termina com espaço/tab (útil p/ achar "lixo")
grep -E '^[[:alpha:]]+$' arquivo    # linha só com letras
```

> **Erro clássico:** escrever `[:digit:]` **sem** os colchetes externos. O correto é `[[:digit:]]`. Sem isso, o padrão vira uma lista com os caracteres `: d i g t`.

### 5.3 Regras especiais **dentro** de colchetes

- Os metacaracteres perdem o significado especial (`.`, `*`, `$`, `\` são literais): `[.*$]` casa um desses três caracteres.
- Para incluir `]`, coloque-o **primeiro**: `[]abc]`.
- Para incluir `-`, coloque-o **primeiro ou último**: `[a-z-]`, `[-a-z]`.
- Para incluir `^` literal, **não** o coloque primeiro: `[a^b]`.
- A barra invertida é **literal** dentro de colchetes na regex POSIX (`[\n]` casa `\` ou `n`, não quebra de linha).

### 5.4 Cuidado com localidade (locale)

Dependendo do `locale`, intervalos como `[a-z]` podem incluir letras maiúsculas ou acentuadas. As classes POSIX (`[[:lower:]]`) são mais seguras. Para comportamento previsível:

```bash
LC_ALL=C grep '[a-z]' arquivo
```

## 6. Quantificadores

Aplicam-se ao **item imediatamente anterior** (um caractere, uma classe ou um grupo).

| Quantificador | BRE | ERE | Significado |
|---------------|-----|-----|-------------|
| Zero ou mais | `*` | `*` | `{0,}` |
| Um ou mais | `\+` | `+` | `{1,}` |
| Zero ou um | `\?` | `?` | `{0,1}` |
| Exatamente `n` | `\{n\}` | `{n}` | |
| Pelo menos `n` | `\{n,\}` | `{n,}` | |
| No máximo `m` | `\{,m\}` | `{,m}` | (extensão GNU) |
| De `n` a `m` | `\{n,m\}` | `{n,m}` | |

```bash
grep -E 'ab*c' arquivo            # ac, abc, abbc, abbbc...
grep -E 'ab+c' arquivo            # abc, abbc... (NÃO casa ac)
grep -E 'ab?c' arquivo            # ac ou abc (e só)
grep -E '^[0-9]{3}$' arquivo      # exatamente 3 dígitos na linha
grep -E '[0-9]{2,4}' arquivo      # de 2 a 4 dígitos
grep -E '^.{10,}$' arquivo        # linhas com 10 ou mais caracteres
grep -E '^.{0,5}$' arquivo        # linhas com até 5 caracteres
```

### 6.1 Diferença entre `*` da regex e `*` do glob

```
Glob:  *.txt        -> qualquer nome terminado em .txt
Regex: .*\.txt$     -> qualquer texto terminado em .txt
Regex: a*           -> zero ou mais "a" (casa até com linha vazia!)
```

> `grep 'a*' arquivo` casa **todas** as linhas, porque "zero ocorrências de a" é válido em qualquer linha.

## 7. Grupos, alternância e retrovisores

### 7.1 Agrupamento

```bash
grep -E '(ab)+' arquivo           # ab, abab, ababab...
grep -E '^(http|https)://' arquivo
grep '^\(http\|https\)://' arquivo   # mesma coisa em BRE
```

### 7.2 Alternância

```bash
grep -E 'erro|falha|critico' log        # ERE
grep 'erro\|falha\|critico' log         # BRE (GNU)
grep -e erro -e falha -e critico log    # várias expressões com -e
```

### 7.3 Retrovisores (backreferences)

`\1` repete exatamente o que o **primeiro grupo** casou; `\2`, o segundo, e assim por diante (até `\9`).

```bash
# Palavras com letra dobrada em sequência (ex.: "aa", "ee")
grep -E '(.)\1' arquivo

# Linhas com palavra repetida em sequência (ex.: "o o")
grep -E '\b([[:alpha:]]+) \1\b' arquivo

# Mesma regra em BRE
grep '\([a-z]\)\1' arquivo

# Linhas que começam e terminam com o mesmo caractere
grep -E '^(.).*\1$' arquivo
```

## 8. Atalhos GNU

Extensões do GNU (funcionam no `grep` e no `sed` do Linux):

| Atalho | Equivale a | Descrição |
|--------|-----------|-----------|
| `\w` | `[[:alnum:]_]` | Caractere de "palavra" |
| `\W` | `[^[:alnum:]_]` | Não é caractere de palavra |
| `\s` | `[[:space:]]` | Espaço em branco |
| `\S` | `[^[:space:]]` | Não é espaço em branco |
| `\b` | — | Limite de palavra |
| `\B` | — | Não é limite de palavra |
| `\<` | — | Início de palavra |
| `\>` | — | Fim de palavra |

```bash
grep '\<root\>' arquivo         # a palavra "root" inteira
grep '\broot\b' arquivo         # igual
grep -w root arquivo            # igual (opção -w)
grep -E '\w+@\w+' arquivo       # algo parecido com e-mail
```

> `\d` (dígito) **não existe** em BRE/ERE do GNU grep (é do PCRE, `grep -P`). Para a prova, use `[0-9]` ou `[[:digit:]]`.

## 9. `grep` em detalhes

### 9.1 Sintaxe

```bash
grep [OPÇÕES] PADRÃO [ARQUIVO...]
comando | grep [OPÇÕES] PADRÃO
```

Se nenhum arquivo for informado, lê a **entrada padrão**.

### 9.2 Opções importantes

| Opção | Efeito |
|-------|--------|
| `-i` | Ignora diferença entre maiúsculas e minúsculas |
| `-v` | **Inverte**: mostra as linhas que **não** casam |
| `-c` | Mostra apenas a **contagem de linhas** que casam |
| `-n` | Mostra o **número da linha** |
| `-l` | Mostra só os **nomes dos arquivos** que contêm correspondência |
| `-L` | Mostra os nomes dos arquivos que **não** contêm correspondência |
| `-o` | Mostra **somente o trecho** que casou (uma ocorrência por linha de saída) |
| `-w` | Casa apenas **palavras inteiras** |
| `-x` | Casa apenas se a **linha inteira** for igual ao padrão |
| `-r` | Busca **recursiva** em diretórios (não segue links simbólicos encontrados na árvore) |
| `-R` | Recursiva **seguindo links simbólicos** |
| `-E` | Usa **ERE** (regex estendida) |
| `-F` | Trata o padrão como **texto fixo** (literal) |
| `-P` | Usa regex compatível com Perl (PCRE) — fora do escopo da prova |
| `-e PADRÃO` | Define um padrão (pode repetir `-e` para vários) |
| `-f ARQUIVO` | Lê os padrões de um **arquivo** (um por linha) |
| `-h` | Omite o nome do arquivo na saída |
| `-H` | Força mostrar o nome do arquivo |
| `-A N` | Mostra **N linhas depois** (After) da correspondência |
| `-B N` | Mostra **N linhas antes** (Before) |
| `-C N` | Mostra **N linhas** antes e depois (Context) |
| `-q` | **Silencioso**: não imprime nada, só retorna o código de saída |
| `-s` | Suprime mensagens de erro (arquivo inexistente, sem permissão) |
| `-m N` | Para após **N** linhas que casam |
| `--color` | Destaca o trecho que casou |
| `--include=GLOB` | Com `-r`, só arquivos que casam com o glob |
| `--exclude=GLOB` | Com `-r`, ignora arquivos que casam com o glob |
| `--exclude-dir=DIR` | Com `-r`, ignora diretórios |

### 9.3 Código de saída (muito útil em scripts)

| Código | Significado |
|--------|-------------|
| `0` | Encontrou **ao menos uma** correspondência |
| `1` | **Nenhuma** correspondência |
| `2` | **Erro** (ex.: arquivo inexistente) |

```bash
if grep -q '^root:' /etc/passwd; then
    echo "root existe"
fi
```

### 9.4 Exemplos práticos

```bash
# Linhas que contêm "bash" no /etc/passwd
grep bash /etc/passwd

# Ignorando maiúsculas/minúsculas
grep -i erro /var/log/syslog

# Contar linhas com "Failed"
grep -c 'Failed' /var/log/auth.log

# Números de linha
grep -n 'PermitRootLogin' /etc/ssh/sshd_config

# Linhas que NÃO são comentário nem vazias
grep -v '^#' /etc/ssh/sshd_config | grep -v '^$'
grep -Ev '^(#|$)' /etc/ssh/sshd_config      # versão única com ERE

# Procurar em todo um diretório, mostrando só nomes de arquivos
grep -rl 'PermitRootLogin' /etc/

# Procurar só em arquivos .conf
grep -r --include='*.conf' 'Listen' /etc/

# Mostrar 2 linhas de contexto
grep -C 2 'ERROR' app.log

# Extrair somente os trechos que casam
grep -oE '[0-9]{1,3}(\.[0-9]{1,3}){3}' access.log     # IPs

# Linhas inteiras iguais ao padrão
grep -x 'root' lista.txt
```

### 9.5 `-c` conta **linhas**, não ocorrências

```bash
echo 'ab ab ab' | grep -c 'ab'      # 1  (uma LINHA casou)
echo 'ab ab ab' | grep -o 'ab' | wc -l   # 3 (três ocorrências)
```

### 9.6 Procurando vários padrões

```bash
grep -e 'erro' -e 'falha' log
grep -E 'erro|falha' log
grep -f padroes.txt log          # lê os padrões de padroes.txt
```

### 9.7 `grep` com pipes

```bash
ps aux | grep sshd
ps aux | grep '[s]shd'           # truque: evita que o próprio grep apareça
dmesg | grep -i usb
cat /etc/passwd | grep -E '^[^:]+:[^:]*:[0-9]{4,}:'
```

### 9.8 Variantes de arquivos compactados

```bash
zgrep 'erro' /var/log/syslog.2.gz
bzgrep ...   # arquivos .bz2
xzgrep ...   # arquivos .xz
```

## 10. `egrep` e `fgrep`

| Comando | Equivale a | Observação |
|---------|-----------|------------|
| `egrep` | `grep -E` | Regex **estendida** |
| `fgrep` | `grep -F` | Padrão **literal** (nenhum caractere é especial) |

```bash
egrep 'gato|cachorro' animais.txt       # = grep -E
fgrep 'a.b*c' arquivo                   # procura literalmente a.b*c
grep -F '$HOME' arquivo                 # procura literalmente $HOME
```

> `egrep` e `fgrep` são considerados **obsoletos** (a documentação recomenda `grep -E` e `grep -F`), mas **continuam na lista do exame**, então conheça ambos.

`fgrep`/`-F` é útil e mais rápido quando o texto contém muitos caracteres especiais que você **não** quer interpretar como regex.

## 11. `sed` em detalhes

O `sed` (*stream editor*) lê o texto **linha por linha**, aplica comandos e imprime o resultado. **Por padrão não altera o arquivo original**: a saída vai para a tela.

### 11.1 Sintaxe

```bash
sed [OPÇÕES] 'COMANDO' [ARQUIVO...]
sed [OPÇÕES] -e 'CMD1' -e 'CMD2' [ARQUIVO...]
sed [OPÇÕES] -f script.sed [ARQUIVO...]
comando | sed 'COMANDO'
```

### 11.2 Opções importantes

| Opção | Efeito |
|-------|--------|
| `-n` | **Suprime** a impressão automática (só imprime o que o comando `p` mandar) |
| `-e` | Adiciona um comando (pode repetir) |
| `-f arq` | Lê comandos de um arquivo |
| `-i[SUF]` | Edita **in loco** (altera o arquivo). Com `SUF`, cria backup (`-i.bak`) |
| `-E` ou `-r` | Usa **ERE** |
| `-s` | Trata cada arquivo separadamente |

### 11.2.1 Cuidado com `-i`

```bash
sed -i 's/foo/bar/g' arquivo        # ALTERA o arquivo, sem backup
sed -i.bak 's/foo/bar/g' arquivo    # altera e guarda a cópia em arquivo.bak
```

### 11.3 O comando de substituição `s`

```
s/REGEX/SUBSTITUIÇÃO/FLAGS
```

| Flag | Efeito |
|------|--------|
| (nenhuma) | Substitui só a **primeira** ocorrência **de cada linha** |
| `g` | Substitui **todas** as ocorrências da linha |
| `N` (número) | Substitui só a **N-ésima** ocorrência |
| `Ng` | Substitui da N-ésima em diante |
| `i` ou `I` | Ignora maiúsculas/minúsculas (GNU) |
| `p` | Imprime a linha se houve substituição (usar com `-n`) |
| `w arq` | Grava no arquivo as linhas em que houve substituição |

```bash
echo 'a a a a' | sed 's/a/X/'      # X a a a
echo 'a a a a' | sed 's/a/X/g'     # X X X X
echo 'a a a a' | sed 's/a/X/2'     # a X a a
echo 'a a a a' | sed 's/a/X/2g'    # a X X X
echo 'Linux' | sed 's/linux/UNIX/I'   # UNIX
```

### 11.3.1 Delimitadores alternativos

O `/` pode ser trocado por outro caractere, o que evita escapar barras em caminhos:

```bash
sed 's/\/usr\/local/\/opt/' arquivo      # com escapes (feio)
sed 's|/usr/local|/opt|' arquivo         # com | como delimitador
sed 's#/usr/local#/opt#' arquivo         # com #
```

### 11.3.2 O `&` e os grupos na substituição

- `&` representa **todo o trecho** que casou.
- `\1`, `\2`... representam os **grupos** capturados.

```bash
echo 'casa' | sed 's/casa/[&]/'                    # [casa]
echo 'Maria Silva' | sed -E 's/(\w+) (\w+)/\2, \1/'  # Silva, Maria
echo 'Maria Silva' | sed 's/\(\w\+\) \(\w\+\)/\2, \1/'  # idem, em BRE
echo '2026-10-29' | sed -E 's/([0-9]{4})-([0-9]{2})-([0-9]{2})/\3\/\2\/\1/'
# 29/10/2026
```

Para um `&` literal na substituição, escape: `\&`.

### 11.3.3 Maiúsculas/minúsculas na substituição (extensão GNU)

| Sequência | Efeito |
|-----------|--------|
| `\U` | Converte o que vem a seguir para **MAIÚSCULAS** |
| `\L` | Converte para **minúsculas** |
| `\u` | Só o **próximo caractere** em maiúscula |
| `\l` | Só o próximo caractere em minúscula |
| `\E` | Encerra `\U` ou `\L` |

```bash
echo 'linux' | sed 's/.*/\U&/'              # LINUX
echo 'linux' | sed 's/^./\u&/'              # Linux
echo 'ola mundo' | sed -E 's/\b(.)/\u\1/g'  # Ola Mundo
```

### 11.4 Endereços (em quais linhas agir)

| Endereço | Significado |
|----------|-------------|
| `N` | A linha número `N` |
| `N,M` | Da linha `N` à `M` |
| `$` | A **última** linha |
| `/regex/` | Linhas que **casam** com a regex |
| `/re1/,/re2/` | Do primeiro casamento de `re1` até o próximo de `re2` |
| `N,+K` | A linha `N` e as `K` seguintes |
| `PRIMEIRA~PASSO` | Ex.: `1~2` = linhas ímpares; `0~2` = pares |
| `ENDEREÇO!` | **Nega** o endereço (aplica nas demais linhas) |

```bash
sed '3s/a/b/' arquivo           # só na linha 3
sed '2,5s/a/b/g' arquivo        # nas linhas 2 a 5
sed '$s/fim/FIM/' arquivo       # só na última linha
sed '/^#/s/foo/bar/' arquivo    # só nas linhas que começam com #
sed '/^#/!s/foo/bar/' arquivo   # em todas EXCETO as que começam com #
```

### 11.5 Outros comandos do `sed`

| Comando | Ação |
|---------|------|
| `p` | **Imprime** a linha |
| `d` | **Apaga** a linha (não imprime) |
| `s` | **Substitui** |
| `y/abc/xyz/` | **Transliteração** caractere a caractere (a→x, b→y, c→z) |
| `a\ texto` ou `a texto` | **Acrescenta** texto **depois** da linha |
| `i\ texto` ou `i texto` | **Insere** texto **antes** da linha |
| `c\ texto` ou `c texto` | **Substitui a linha inteira** por texto |
| `q` | **Sai** (quit) após imprimir a linha atual |
| `=` | Imprime o **número** da linha atual |
| `r arq` | Lê e insere o conteúdo de `arq` depois da linha |
| `w arq` | **Grava** a linha em `arq` |

#### Imprimir (`p`) com `-n`

```bash
sed -n '5p' arquivo              # só a linha 5
sed -n '2,4p' arquivo            # linhas 2 a 4
sed -n '$p' arquivo              # última linha
sed -n '/erro/p' arquivo         # equivale a grep erro
sed -n '/inicio/,/fim/p' arquivo # bloco entre dois marcadores
```

> **Pegadinha:** `sed '2p' arquivo` **sem** `-n` imprime a linha 2 **duas vezes** (uma pelo `p`, outra pela impressão automática).

#### Apagar (`d`)

```bash
sed '1d' arquivo                 # remove a 1ª linha
sed '$d' arquivo                 # remove a última linha
sed '2,4d' arquivo               # remove as linhas 2 a 4
sed '/^$/d' arquivo              # remove linhas vazias
sed '/^#/d' arquivo              # remove comentários
sed '/^\s*#/d;/^$/d' arquivo     # comentários (mesmo indentados) e linhas vazias
```

#### Transliterar (`y`)

```bash
echo 'linux' | sed 'y/abcdefghijklmnopqrstuvwxyz/ABCDEFGHIJKLMNOPQRSTUVWXYZ/'
# LINUX
echo 'a-b-c' | sed 'y/-/_/'      # a_b_c
```

> `y` **não usa regex**: apenas mapeia caractere por caractere. Os dois conjuntos devem ter o **mesmo tamanho**.

#### Acrescentar, inserir, trocar

```bash
sed '3a Texto depois da linha 3' arquivo
sed '3i Texto antes da linha 3' arquivo
sed '3c Linha 3 substituída' arquivo
sed '/^\[main\]/a opcao=1' config.ini
```

#### Sair antes (`q`)

```bash
sed '5q' arquivo                 # imprime as 5 primeiras linhas e sai (como head -5)
```

### 11.6 Múltiplos comandos

```bash
sed -e 's/a/b/' -e 's/c/d/' arquivo
sed 's/a/b/;s/c/d/' arquivo
sed -e '/^#/d' -e '/^$/d' arquivo
```

### 11.7 Resumo: `sed` não modifica o arquivo (sem `-i`)

```bash
sed 's/foo/bar/g' arquivo > novo.txt     # redireciona para um novo arquivo
sed -i 's/foo/bar/g' arquivo             # altera o próprio arquivo
```

> **Cuidado:** `sed 's/foo/bar/' arquivo > arquivo` **zera** o arquivo (o shell trunca antes de o `sed` ler). Use `-i` ou um arquivo temporário.

```bash
# Linhas que começam com vogal

# Linhas que terminam com ponto

# Usuários com shell /bin/bash

# Endereço de e-mail (forma simples)
grep -E '[[:alnum:]._-]+@[[:alnum:].-]+\.[a-z]{2,}' arquivo

# Data no formato dd/mm/aaaa
grep -E '[0-9]{2}/[0-9]{2}/[0-9]{4}' arquivo

# CEP brasileiro 00000-000
grep -E '^[0-9]{5}-[0-9]{3}$' arquivo

# Telefone (11) 91234-5678
grep -E '\([0-9]{2}\) ?9?[0-9]{4}-[0-9]{4}' arquivo

# Linhas com 80+ caracteres
grep -E '^.{80,}' arquivo

# Remover espaços no início e no fim da linha
sed 's/^[[:space:]]*//;s/[[:space:]]*$//' arquivo

# Remover espaços finais
sed 's/[[:space:]]*$//' arquivo

# Remover todos os dígitos
sed 's/[0-9]//g' arquivo

# Trocar "foo" por "bar" em todos os .conf (com backup)
sed -i.bak 's/foo/bar/g' *.conf

# Comentar uma linha que contém "PermitRootLogin"
sed -i '/PermitRootLogin/s/^/#/' /etc/ssh/sshd_config

# Descomentar
sed -i '/PermitRootLogin/s/^#//' /etc/ssh/sshd_config

# Numerar linhas não vazias (junto com outros comandos)
sed '/./=' arquivo | sed '/./N; s/\n/ /'

# Duplicar linha vazia ou separar com linha em branco
sed 'G' arquivo

# Imprimir só o 2º campo de /etc/passwd (equivale a cut -d: -f2)
sed -E 's/^[^:]*:([^:]*).*/\1/' /etc/passwd

# Contar ocorrências de uma palavra (não só linhas)
grep -o 'palavra' arquivo | wc -l
```

## 14. Cheat sheet

### Caracteres especiais

```
.        qualquer caractere
*        zero ou mais do anterior
^        início da linha
$        fim da linha
[abc]    um dentre a, b, c
[^abc]   qualquer um, exceto a, b, c
[a-z]    intervalo
\        escape
```

### BRE × ERE

```
BRE (grep, sed)         ERE (grep -E, egrep, sed -E)
\+                      +
\?                      ?
\{n,m\}                 {n,m}
\( \)                   ( )
\|                      |
```

### Classes POSIX

```
[[:alpha:]] [[:digit:]] [[:alnum:]] [[:upper:]] [[:lower:]]
[[:space:]] [[:blank:]] [[:punct:]] [[:xdigit:]]
```

### grep — opções mais cobradas

```
-i  ignora caixa      -v  inverte           -c  conta linhas
-n  nº da linha       -l  só nomes          -o  só o trecho
-w  palavra inteira   -x  linha inteira     -r  recursivo
-E  ERE (= egrep)     -F  literal (= fgrep) -A/-B/-C  contexto
```

### sed — essencial

```
sed 's/a/b/'        1ª ocorrência por linha
sed 's/a/b/g'       todas as ocorrências
sed -n '2,4p'       imprime linhas 2 a 4
sed '/x/d'          apaga linhas com x
sed '3d'            apaga a linha 3
sed 'y/abc/xyz/'    transliteração
sed -i.bak ...      edita o arquivo (com backup)
sed -E ...          usa ERE
&                   o trecho casado
\1 \2               grupos capturados
```

## 15. Armadilhas comuns na prova

1. **BRE × ERE:** `grep 'a+'` procura "a+" **literal**. Para "um ou mais a": `grep 'a\+'` ou `grep -E 'a+'`.
2. **`.` sem escape:** casa **qualquer** caractere. Para o ponto literal: `\.`.
3. **`*` não é "qualquer coisa":** é "zero ou mais do item anterior". O equivalente do glob `*` é `.*`.
4. **`a*` casa tudo**, inclusive linhas sem nenhum `a` (zero ocorrências).
5. **`[:digit:]` sem colchetes externos:** o correto é `[[:digit:]]`.
6. **`^` dentro de colchetes** (`[^abc]`) é **negação**; fora, é **âncora**.
7. **`grep -c`** conta **linhas**, não ocorrências. Para ocorrências: `grep -o ... | wc -l`.
8. **`sed 's/a/b/'`** só troca a **primeira** ocorrência por linha. Para todas, `g`.
9. **`sed` sem `-i`** **não altera** o arquivo.
10. **`sed '2p'` sem `-n`** imprime a linha 2 **em dobro**.
11. **`sed -n '/x/p'`** equivale a `grep x`.
12. **`sed '/x/d'`** equivale a `grep -v x`.
13. **`sed 's/a/b/' f > f`** apaga o conteúdo do arquivo.
14. **`egrep` = `grep -E`** e **`fgrep` = `grep -F`**.
15. **`grep -F`** não interpreta nenhum metacaractere (nem `.` nem `*`).
16. **`-r` × `-R`:** ambos recursivos; só o `-R` segue links simbólicos.
17. **`-l` × `-L`:** `-l` lista arquivos **com** correspondência; `-L` os **sem**.
18. **`-w` × `-x`:** `-w` = palavra inteira; `-x` = linha inteira.
19. **Aspas duplas** deixam o shell expandir `$variáveis` dentro do padrão. Prefira aspas simples.
20. **Guloso:** `.*` consome o máximo. Para "até o próximo `>`" use `[^>]*`.
21. **`\d` não existe** no `grep` comum. Use `[0-9]` ou `[[:digit:]]`.
22. **Código de saída do `grep`:** `0` achou, `1` não achou, `2` erro.
23. **`y` do `sed` não é regex** e exige conjuntos do mesmo tamanho.
24. **Delimitador alternativo no `s`:** `s|a|b|` e `s#a#b#` são válidos.
