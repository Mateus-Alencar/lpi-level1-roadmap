# LPIC-1 · 104.3 · Montagem e desmontagem de sistemas de arquivos (peso 3)

**Cobrado no exame:** `/etc/fstab`, `/media/`, `mount`, `umount`, `blkid`, `lsblk`.

---

## 1. Conceitos

- Linux tem **uma árvore única** a partir de `/`. **Montar** = anexar um dispositivo a um diretório (ponto de montagem).
- O ponto de montagem **precisa existir** (`mkdir`). Se já tiver arquivos, eles ficam **ocultos** (não apagados) até desmontar.
- **`/mnt`**: montagens temporárias manuais do administrador. **`/media`**: mídias removíveis (CD, pendrive), normalmente automontadas pelo desktop (udisks2).
- Desmontar corretamente faz o *flush* do cache. `sync` força a gravação, mas **não substitui** o `umount`.

## 2. Descobrir dispositivos e montagens

| Comando | Para quê |
|---|---|
| `lsblk` | Árvore de dispositivos (**sem** UUID) |
| `lsblk -f` | Mostra FSTYPE, LABEL, UUID e MOUNTPOINT (não precisa de root) |
| `blkid` | UUID, LABEL, TYPE (normalmente precisa de root) |
| `blkid -L LABEL` / `blkid -U UUID` | Descobre o dispositivo pelo label/UUID |
| `mount` (sem args) | Lista tudo que está montado |
| `findmnt` | Árvore de montagens |
| `findmnt --verify` | **Valida o fstab** |
| `df -hT` | Espaço, tipo e ponto de montagem |
| `/proc/mounts` | Lista real do kernel |
| `/etc/mtab` | Hoje é link simbólico para `/proc/self/mounts` |

Links estáveis em `/dev/disk/`: `by-uuid`, `by-label`, `by-id`, `by-path`, `by-partuuid`.

## 3. `mount`

```bash
mount [-t TIPO] [-o OPÇÕES] DISPOSITIVO PONTO
mount /dev/sdb1 /mnt/dados
mount -t ext4 -o ro,noexec /dev/sdb1 /mnt/dados
mount UUID=xxxx /mnt/dados        # ou: mount -U xxxx
mount LABEL=DADOS /mnt/dados      # ou: mount -L DADOS
mount /mnt/dados                  # só 1 argumento: busca o resto no fstab
```

| Opção | Função |
|---|---|
| `-t` | Tipo do filesystem |
| `-o` | Opções separadas por vírgula |
| `-a` | Monta **tudo** do fstab (**exceto `noauto`**) |
| `-r` / `-w` | Somente leitura / leitura e escrita |
| `-L` / `-U` | Seleciona por label / UUID |
| `--bind` | Monta um diretório em outro lugar |
| `--rbind` | Bind recursivo |
| `--move` | Move um ponto de montagem |

**Remount** (altera opções **sem desmontar**; típico para a raiz):

```bash
mount -o remount,rw /
mount -o remount,ro /
```

**Bind:** `mount --bind /var/www /srv/ftp/site`. No fstab: `/var/www /srv/ftp/site none bind 0 0`.

**ISO / loop:** `mount -o loop imagem.iso /mnt/iso` (o `loop` faz um arquivo comum agir como dispositivo de bloco).

**Rede:** `mount -t nfs servidor:/export /mnt/nfs`, `mount -t cifs //servidor/share /mnt/smb -o username=...`. No fstab use `_netdev`.

**Tipos comuns:** ext2/3/4, xfs, btrfs, vfat (FAT32), exfat, ntfs-3g, iso9660 (CD/DVD), udf, nfs, cifs, tmpfs (RAM).

## 4. Opções de montagem (`-o` e 4º campo do fstab)

| Opção | Oposto | Significado |
|---|---|---|
| `rw` | `ro` | Leitura+escrita / somente leitura |
| `exec` | `noexec` | Permite executar binários |
| `suid` | `nosuid` | Honra SUID/SGID |
| `dev` | `nodev` | Interpreta arquivos de dispositivo |
| `auto` | `noauto` | Monta no boot / com `mount -a` |
| `user` | `nouser` | Usuário comum pode montar |
| `async` | `sync` | Escrita assíncrona / síncrona |

Outras: `users`, `owner`, `group`, `remount`, `nofail`, `_netdev`, `loop`, `bind`, `atime/relatime/noatime`.

**Memorize:**

- **`defaults` = `rw, suid, dev, exec, auto, nouser, async`**
- **`user`, `users`, `owner`, `group` implicam `noexec,nosuid,nodev`**, a menos que `exec`/`suid`/`dev` venha **depois** deles. **A ordem importa:**
  - `user,exec` → exec habilitado
  - `exec,user` → exec **não** habilitado (o `noexec` implícito vem depois)
- `relatime` é o padrão moderno do kernel.
- `nofail`: o boot continua se o disco não existir. `noauto`: não monta automaticamente.
- **FAT/NTFS não têm permissões Unix**: use `uid=`, `gid=`, `umask=`, `fmask=`, `dmask=` no mount.
- XFS com UUID duplicado: `-o nouuid`.

## 5. `umount`

- Grafia: **`umount`** (sem o "n"). `unmount` está errado.
- Aceita o **ponto de montagem** ou o **dispositivo**: `umount /mnt/dados` ou `umount /dev/sdb1`.

| Opção | Função |
|---|---|
| `-a` | Desmonta tudo listado |
| `-t TIPO` | Restringe por tipo |
| `-f` | **Força** (útil para NFS inacessível) |
| `-l` | **Lazy**: tira da árvore agora e finaliza quando deixar de estar ocupado |
| `-r` | Se falhar, remonta como somente leitura |

**"target is busy"**: há processo usando o filesystem (inclusive um shell com `cd` dentro dele).

```bash
fuser -vm /mnt/dados     # quem usa
lsof /mnt/dados          # arquivos abertos
fuser -km /mnt/dados     # MATA os processos (cuidado)
```

Resolução: sair do diretório (`cd ~`), encerrar processos, tentar de novo, e só em último caso `umount -l`.

**Quem desmonta:** root sempre. Usuário comum só se estiver no fstab com `user` (e foi ele quem montou) ou `users`.

## 6. `/etc/fstab`

Lido no boot, por `mount -a` e por `mount`/`umount` com **um só argumento**. Seis campos, separados por espaços ou tabs:

```
<dispositivo>  <ponto>  <tipo>  <opções>  <dump>  <pass>
```

| # | Campo | Valores |
|---|---|---|
| 1 | Dispositivo | `/dev/sdb1`, `UUID=`, `LABEL=`, `PARTUUID=`, `PARTLABEL=`, `servidor:/export` |
| 2 | Ponto de montagem | Diretório (`none` para swap) |
| 3 | Tipo | ext4, xfs, vfat, nfs, swap, tmpfs, `auto`... |
| 4 | Opções | Separadas por vírgula, **sem espaços** |
| 5 | **dump** | `0` = fora do backup do `dump`; `1` = incluir (quase sempre `0`) |
| 6 | **pass** (fsck) | `1` = raiz; `2` = demais; `0` = não verifica |

- **pass `0`** para swap, tmpfs, rede, **XFS e Btrfs**.
- `#` = comentário. Espaço no caminho: `\040`.
- `/dev/sdX` **não é estável** (muda com a ordem dos discos). Prefira **UUID**.

**Exemplos que você precisa saber ler:**

```fstab
UUID=3f8e...  /          ext4  errors=remount-ro  0 1
LABEL=HOME    /home      ext4  defaults,noatime   0 2
UUID=c0ff...  /dados     xfs   defaults,nofail    0 0
UUID=9b7c...  none       swap  sw                 0 0
/dev/sdb1     /media/usb vfat  user,noauto,uid=1000  0 0
/dev/sr0      /media/cdrom iso9660 ro,user,noauto 0 0
servidor:/exp /mnt/nfs   nfs   defaults,_netdev   0 0
tmpfs         /tmp       tmpfs defaults,size=512m 0 0
/var/www      /srv/ftp/site none bind             0 0
```

**Aplicar mudanças sem reiniciar:**

```bash
findmnt --verify          # valida
systemctl daemon-reload   # recarrega as units geradas
mount -a                  # testa
```

**Nunca reinicie sem testar com `mount -a`.** Um fstab com erro pode levar ao modo de emergência.

**Recuperação (modo de emergência):** `mount -o remount,rw /` → editar/comentar a linha com erro no `/etc/fstab` → `systemctl daemon-reload` → `mount -a` → `reboot`.

**Opções do systemd no fstab:** `x-systemd.automount` (monta no 1º acesso), `x-systemd.idle-timeout=`, `x-systemd.device-timeout=`.

## 7. UUID e LABEL

| Identificador | Onde fica | Observação |
|---|---|---|
| UUID | Superbloco do filesystem | Gerado no `mkfs`; **muda ao reformatar** (atualize o fstab) |
| LABEL | Superbloco do filesystem | Pode ter **duplicatas** |
| PARTUUID / PARTLABEL | Tabela de partições (GPT) | Útil quando o filesystem não tem UUID |

**Definir label:**

| Filesystem | Comando | Limite |
|---|---|---|
| ext2/3/4 | `e2label DISP NOME` ou `tune2fs -L NOME DISP` | 16 caracteres |
| XFS | `xfs_admin -L NOME DISP` (desmontado) | 12 caracteres |
| Btrfs | `btrfs filesystem label DISP NOME` | |
| FAT | `fatlabel DISP NOME` (ou `dosfslabel`) | 11 caracteres |
| NTFS | `ntfslabel DISP NOME` | |
| swap | `swaplabel -L NOME DISP` | |
| Na criação | `mkfs.ext4 -L`, `mkfs.xfs -L`, `mkswap -L` | |

**Alterar UUID:** `tune2fs -U random DISP` (ext), `xfs_admin -U generate DISP` (XFS), `swaplabel -U` (swap). Útil após clonar disco com `dd` (UUID duplicado).

**Consultar:** `blkid`, `lsblk -f`, `tune2fs -l DISP`, `xfs_admin -u -l DISP`.

**UUID x LABEL:** UUID é praticamente único (recomendado em servidores/fstab). LABEL é legível, mas não garantido único (bom para removíveis).

## 8. Usuário comum montando

Por padrão **só o root** monta. Para liberar, o fstab precisa de **`user`**, **`users`**, **`owner`** ou **`group`**.

| Opção | Quem monta | Quem desmonta |
|---|---|---|
| `user` | Qualquer usuário | **Só quem montou** (e root) |
| `users` | Qualquer usuário | **Qualquer usuário** |
| `owner` | Dono do dispositivo (`/dev/sdb1`) | O mesmo |
| `group` | Membros do grupo do dispositivo | O mesmo |

```fstab
/dev/sdb1  /media/usb  vfat  user,noauto,uid=1000,umask=022  0 0
```

```bash
mount /media/usb                      # OK: só o ponto de montagem
mount -t vfat /dev/sdb1 /mnt/outro    # ERRO: "only root can do that"
```

- O usuário monta **só o que está no fstab**, informando **apenas o ponto OU o dispositivo**.
- `noauto` junto com `user` evita a montagem no boot (mídia removível pode estar ausente).

## 9. Swap

Não é "montada": usa `swapon`/`swapoff`, mas aparece no fstab.

```bash
mkswap /dev/sda3     # cria (gera UUID)
swapon /dev/sda3     # ativa
swapon -a            # ativa tudo do fstab
swapoff /dev/sda3    # desativa
swapon --show        # lista (ou cat /proc/swaps, free -h)
```

```fstab
UUID=9b7c...  none  swap  sw  0 0     # ponto = none, tipo = swap, opção = sw
```

Pode ser arquivo (`/swapfile none swap sw 0 0`) e ter prioridade (`sw,pri=10`).

## 10. Mount units do systemd (conhecimento)

- Cada ponto de montagem é uma unit **`.mount`**. Vêm de **(1)** geradas do fstab pelo `systemd-fstab-generator` (temporárias, em `/run/systemd/generator/`) ou **(2)** escritas em `/etc/systemd/system/` (têm **precedência**).
- **Nome do arquivo = caminho do ponto de montagem**: remove a `/` inicial, troca as demais `/` por `-`, sufixo `.mount`.

| Ponto | Unit |
|---|---|
| `/` | `-.mount` |
| `/home` | `home.mount` |
| `/mnt/dados` | `mnt-dados.mount` |
| `/var/lib/mysql` | `var-lib-mysql.mount` |

Gerar o nome: `systemd-escape -p --suffix=mount /var/lib/mysql`. Se o nome não bater com `Where=`, o systemd **recusa** a unit.

```ini
[Unit]
Description=Disco de dados

[Mount]
What=/dev/disk/by-uuid/c0ffee00-...
Where=/mnt/dados
Type=ext4
Options=defaults,noatime

[Install]
WantedBy=multi-user.target
```

| Diretiva | Equivale no fstab a |
|---|---|
| `What=` | Campo 1 |
| `Where=` | Campo 2 (caminho absoluto) |
| `Type=` | Campo 3 |
| `Options=` | Campo 4 |

Não existe equivalente a dump/pass.

**Automount** (sob demanda): crie `mnt-dados.automount` com `[Automount]`, `Where=` e `TimeoutIdleSec=`. Você **habilita o `.automount`**, não o `.mount`:

```bash
systemctl daemon-reload
systemctl enable --now mnt-dados.automount
```

**Úteis:** `systemctl list-units -t mount`, `systemctl status X.mount`, `systemctl start/stop X.mount` (monta/desmonta), `systemctl cat X.mount`, `journalctl -u X.mount`, `systemctl --failed`.

## 11. Troubleshooting rápido

| Mensagem | Causa / solução |
|---|---|
| `wrong fs type, bad option, bad superblock` | Tipo errado, FS corrompido ou falta driver (`ntfs-3g`). Confira com `blkid`/`lsblk -f`; `fsck` |
| `mount point does not exist` | `mkdir -p` |
| `special device /dev/sdX does not exist` | Nome mudou: use UUID/LABEL |
| `only root can do that` | Falta `user` no fstab |
| `target is busy` | `fuser -vm`, `lsof`, sair do diretório, `umount -l` |
| `already mounted or mount point busy` | Já montado; confira com `findmnt` |
| `Read-only file system` | Montado `ro` ou erro forçou `ro`: `mount -o remount,rw`; veja `dmesg` e `fsck` |
| XFS: UUID duplicado | `mount -o nouuid` ou `xfs_admin -U generate` |

Diagnóstico: `dmesg | tail`, `journalctl -b -p err`, `systemctl --failed`.

## 12. Pegadinhas de prova

1. **`umount`**, nunca `unmount`.
2. **`mount -a` ignora `noauto`.**
3. Usuário comum monta só o que está no fstab com `user/users/owner/group`, informando **um só** argumento.
4. `user`: só quem montou desmonta. `users`: qualquer um.
5. **Ordem das opções:** `user,exec` habilita exec; `exec,user` não.
6. Fonte real das montagens: **`/proc/mounts`**; `/etc/mtab` é só um link.
7. **`mkfs` gera novo UUID** e deixa o fstab desatualizado.
8. **5º campo = dump, 6º = pass (fsck).** Não inverta.
9. **`nofail`** não trava o boot se o disco faltar; **`noauto`** impede a montagem automática.
10. **`remount`** muda opções sem desmontar (método típico para `rw`/`ro` na raiz).
11. **`umount -l`** (lazy) ≠ **`umount -f`** (force, para NFS).
12. `/mnt/dados` → **`mnt-dados.mount`**; `Where=` deve bater com o nome.
13. No automount, habilita-se o **`.automount`**.
14. FAT/NTFS: permissões via `uid=`, `gid=`, `umask=`.
15. Montar sobre diretório não vazio **oculta**, não apaga.
16. **`lsblk` sozinho não mostra UUID**; `lsblk -f` e `blkid` mostram.
17. Swap: `swapon/swapoff`, mas aparece no fstab com ponto `none`.
